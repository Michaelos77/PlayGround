# GREEN HELL — Amazon Survival

A small browser-based 3D rainforest survival game. Explore the forest, gather supplies, and stay alive for three in-game days.

## Play

Serve the project directory locally (ES modules need HTTP):

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a modern browser. Three.js is loaded from jsDelivr, so an internet connection is needed.

## Controls

- **WASD** — move; **mouse** — look around; **Shift** — sprint
- **E** — gather nearby branches, stones, berries, or drink at the river
- **F** — eat gathered berries
- Gather **3 sticks and 2 stones**, then build a lean-to from the pack panel
- On touch screens, use the on-screen joystick and action buttons

Survive for three in-game days while monitoring hydration, nourishment, health, and stamina.
